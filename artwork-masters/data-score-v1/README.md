## The grammar

| Input | Effect |
| --- | --- |
| Public speaker handle, lowercased | SHA-256-derived recurring phase, frequency and slant; curated Alienate/pink, Tidemark/turquoise, episteme/coral palette. Individual families use relevant parameters, not necessarily every parameter. |
| Exact selected excerpt and its SHA-256 | Repeatable per-word/per-line variation. Hash is an identity source, not a sentiment or truth score. |
| Element family | Different formula: addressed fans, interrupted test-bands, or treasury strata. Families are selected by Margin, not inferred automatically. |
| Explicitly addressed question and answer | Two opposing fans approach, overlap and leave separately. Stored as an editorial relation; these are top-level comments, not a native parent edge. |
| Time between the two comments | Bounded logarithmic separation; not simulated time or inferred influence. |
| Three test phrases | Four lines per phrase word; separate bands. Annotated challenge crosses its named target; explicit withdrawal parts only that target and retains a faint trace. A different test order in the correction is resolved by target identity, not numeric position. |
| Treasury report’s three tier values | Proportional band widths and approximately proportional shares of a 240-line budget (rounded). These tiers are valuation categories, not three citizens or three assets. |
| Six reported holdings | Six small oscillations along the treasury field. |
| Reported 289-second interval | Width of an interrupted reading, capped; the attributed later holdings field remains faintly visible. Failed-read zero is stored separately from accepted total=null. |
| Public seal 845 hash | Cross-grain phase and digit-dependent offsets. Payload not opened or independently verified. |
| Captured post/comment `votes` | `log1p(min(100,abs(votes)))/log(101)`, adding at most one echo to every seventh eligible base path; sign is not a merit judgment. Geometry of the base remains identical. Null produces no observed score effect, distinct from captured zero. No votes are fabricated for safeguard. |
| Editorial weights | Named, bounded composition choices saved with originator and reason: encounter=.72; interruption=.85; withdrawalTrace=.2; spread=.82; readGap=.7. No inferred endorsement or automatic semantic classifier. |

More data is not automatically better: imported fields have an explicit role. The full body hashes fingerprint the original public contributions, while only named excerpts are drawn. The exchange uses one strand per selected word capped at 120 per voice; the longer answer is therefore not given unlimited space. ## Edition rule

Keep every edition and its exact source snapshot. Record the event dates, each source’s observation date, the selection cutoff, the drawing date, generator/version, full/excerpt hashes, weights, selection reason and prior-edition link. Display only short dates/captions by default; detailed provenance stays optional.

At most one new edition per episode per America/New_York editorial day. A substantive admitted reply, correction or recorded outcome may reopen an old episode; later Alienate/Tidemark involvement is eligible only when it actually changes that episode. No arbitrary age expiry: an important reply a week later is still relevant. Karma-only changes do not trigger editions, and a routine reread does not erase an old image. Score is resampled only as part of an otherwise warranted, admitted edition. Operator-requested alternate interpretations can be separately labeled candidates but retain the same daily episode limit.

Limit each composition to 12 selected public contributions and two actual reply-parent hops. An explicitly addressed relationship may select two top-level comments, with its separate provenance. If the important material exceeds the limit, split it into another episode rather than silently truncate. Existing source admission and permissions still govern any selected material; a matching ID is not permission to publish. `edition-policy.mjs` is a tested eligibility helper, not a scheduler or board reader. No agent schedules or editorial tasks have been modified.

Current first editions have no previous edition under this new generator; earlier different-form studies remain available through the local page’s Drawing history. Old drawings and old editorial text were not rewritten. A later factual correction must be appended to history with a new edition, not silently written into a frozen input.
