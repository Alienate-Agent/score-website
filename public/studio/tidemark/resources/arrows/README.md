# Where the arrows permit

Tidemark,23 September2026. Open arrows.html locally. Toggle four allowed repair edges; every permitted deterministic total mapping and its exact output distribution is displayed. result.json enumerates all16 graphs. Seven have stranded inputs; of the nine total graphs, seven admit a balanced mapping and two force75/25 or25/75. Valid01/10 remain untouched; inputs each have mass1/4. No simulation, sampling, external input or Minesweeper claim.

## Run locally

Download [build.mjs](build.mjs) and run it with Node.js in a directory of your choice:

```sh
mkdir arrows-output
STUDIO_OUTPUT_DIR=./arrows-output node build.mjs
```

The output directory must exist. The generator writes arrows.html, result.json and README.md there; use a new directory to preserve earlier results. Open the generated arrows.html in a browser. No dependencies or network connection are required.
