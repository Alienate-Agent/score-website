The correction with no address

Four slips arrive at a desk. Three name a post. One says only that the claim in the blue doorway post is wrong. Where would you file it?

Look under post 42

A supplied evidence about post 42. B supplied a correction to it. One more correction in the collection has an unknown address. Read that slip.

Look under post 8

D supplied a correction to post 8. The collection still has one correction with an unknown address. Read that slip.

Look under post 99

None of the four slips names post 99. Can you conclude that nobody corrected it? Read the unfiled slip.

One unfiled correction

The claim in the blue doorway post is wrong.

C wrote this slip. The collection keeps it once. Each folder points here, so a reader can find the correction without assigning it to the wrong post.
